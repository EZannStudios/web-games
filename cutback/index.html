About the game

Drop each block, then swipe to slice off the overhang before the tower topples. Land a block wider than the last and race the Cutback Time bar — trim it to the exact width below for a Perfect and a score multiplier that climbs with every clean cut in a row.

One misjudged balance and it all comes down. Easy one-finger play, chunky slices, and an endless chase for the perfect combo. How high can you stack before the crash?

Features

  • Swipe-to-slice controls with one finger.
  • Perfect cuts build a climbing score multiplier.
  • Real physics: an off-balance tower really topples.
  • A wrecking ball that swings in to test your tower.
  • Block skins to unlock with coins: Food, Classic, Neon and Construction.
  • Online leaderboard on Playgama.

How to play

  1. Tap to drop each block onto the tower.
  2. If a block lands off-balance and hangs over the edge, swipe across it to cut off the overhang before the tower topples.
  3. When a block is wider than the one below, a Cutback Time bar appears. Swipe to trim it to the exact width of the block below for a Perfect.
  4. Each Perfect in a row raises your score multiplier. Stack as high as you can!
